🛍️ NEXMART
A simple online shopping app built with just one HTML file. No installs needed — just open and use!
---
🚀 How to Run
Download `nexmart.html`
Double-click it
It opens in your browser — done!

🛒 What You Can Do
As a shopper:
Browse and search products
Add items to cart
Checkout and track your orders
As an admin:
Add, edit, or delete products
Manage orders
View sales analytics

HTML
CSS
JavaScript
